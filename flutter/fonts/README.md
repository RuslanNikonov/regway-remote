# Bundled client fonts

Headings: **Unbounded** (SIL Open Font License 1.1) — see `OFL-Unbounded.txt`.
Body: **Manrope** (SIL Open Font License 1.1) — see `OFL-Manrope.txt`.

Both families are bundled as variable TTF assets so the desktop client works offline
and in CI without downloading from Google Fonts at runtime.
