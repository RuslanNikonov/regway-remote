# Правило: акцентные кнопки
Все акцентные кнопки и включённые переключатели — одноцветные #38d9ff с тёмным текстом #04030b. Оранжево-синий градиент на кнопках не используется. Тёплые цвета — только для акцентов и ошибок, не для действий.
