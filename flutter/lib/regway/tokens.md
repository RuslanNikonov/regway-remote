# Правило: акцентные кнопки
Все акцентные кнопки и включённые переключатели — одноцветные #38d9ff с тёмным текстом #04030b. Оранжево-синий градиент на кнопках не используется. Тёплые цвета — только для акцентов и ошибок, не для действий.

# v4 (Updates)

Настройки → Обновления. Режимы Авто / Вручную. Источник: `https://remote.regway.group/updates/manifest.json` (+ `.sig`).

| Токен / элемент | Значение | Применение |
|---|---|---|
| progress line | Manrope 400, muted | «Загрузка… N % · докачка после обрыва» |
| retry | button-primary + ghost | после 3 неудач: «Не удалось скачать обновление. Проверьте соединение», кнопка «Повторить» |
| badge | точка accent 8px | пункт «Настройки» в сайдбаре, когда есть доступное/готовое обновление |
| notify | системное уведомление ОС | появление новой версии |
| auto-install | — | установка только после конца активного сеанса |

# v4.1

- `manifest.json` и `manifest.json.sig` качаются Range-кусками ≤16 КиБ с докачкой, не одним GET.
- Манифест >15 КиБ отклоняется **до** проверки подписи.
- Откат запрещён, если у версии `rollback_allowed: false`.
- macOS: `xattr -r -d com.apple.quarantine`, затем перезапуск сервиса.
